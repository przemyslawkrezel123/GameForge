## Start aplikacji

Poniższa instrukcja pozwoli uruchomić pełne środowisko deweloperskie (Frontend, Backend, Baza Danych).

### Wymagania
* Zainstalowany **Docker** oraz **Docker Compose**.

### Instrukcja uruchomienia

**1. Pobranie repozytorium**
Otwórz terminal i sklonuj projekt na swój komputer:

```bash
git clone https://github.com/przemyslawkrezel123/GameForge.git
```

**2. Przejdź do katalogu repozytorium**

```bash
cd GameForge 
```

**3. Uruchomienie aplikacji**
Otwórz terminal i plik docker-compose.yml:

```bash
docker compose up
```
